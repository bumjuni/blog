#프로그래머스 #알고리즘 #완전탐색 

## 문제
- 입력 
	- 중앙은 노란색, 테두리 1줄은 갈색인 직사각형 격자 모양 카펫의
	  갈색 격자 수 `brown`, 노란색 격자 수 `yellow`
- 출력
	- 카펫의 가로, 세로 크기를 순서대로 담은 배열

## 분석 (Plan)
- `w`를 가로, `h`를 세로라고 했을 때, 곱해서 일정한 상수 값이 되어야 함
- 따라서 변수는 2개가 아니라 하나
- 가로 길이 >= 세로 길이여야 하므로 w의 최댓값은 1,000,000
- 입력값이 $10^6$이므로 모든 가능한 `w`에 대해 완전 탐색 알고리즘을 적용할 수 있음
- 시간복잡도: $O(n)$
- 알고리즘: 완전탐색

## 구현 (Do)
```
1. 세로 값이 가로 값보다 크면 종료
2. 전체 노란 면적에서 세로 값을 나눴을 때 가로 값이 정수가 아니면 패스
3. 노란색 세로 값, 가로 값을 이용해서 갈색 면적을 계산
4. 갈색 면적이 같지 않으면 세로 값을 1씩 증가하며 무한 반복

WHILE (TRUE) {
	IF 노랑_세로 > 노랑_가로
		BREAK
		
	IF 노랑_면적에서 노랑_세로를 나눴을 때 정수가 아니라면
		노랑_세로 값 1 증가
		CONTINUE
	
	갈색 면적 = 2 * (노랑_세로 + 노랑_가로) + 4
	
	갈색 면적이 주어진 값과 같으면
		정답 배열에 전체 가로 값 계산해서 넣기 (노랑_가로_ + 2)
		정답 배열에 전체 세로 값 계산해서 넣기 (노랑_세로 + 2)
	갈색 면적이 주어진 값과 같지 않으면
		노랑_세로 값 1 증가
}
```

## 결과 (Check)
- 정답

## 개선 (Action)
- 현재 코드의 단점
	- 무한 반복문으로 쓸 필요가 없음
	- 노란색과 갈색의 면적, 길이를 따로 생각하여 변수명과 계산이 복잡함 
	  (전체 가로, 세로 변수 만으로도 전부 계산할 수 있음)
- 개선 코드
 ```
	int h = 3;
	int w = brown / 2 - 1;
	while (w >= h) {
		if ((w-2) * (h-2) == yellow) {
			return {w, h};
		}
		
		w--;
		h++;
	}  
	
	return {};
 ```
-  `w + h`가 일정하다는 특징을 사용하여 매 반복문마다 `w`, `h`값 조절
	- `brown = 2(w + h) - 4`에서 `brown`은 상수이므로 `w + h`값은 일정

- 정답 배열을 바로 벡터로 만들어서 반환 ⇒ 가독성
