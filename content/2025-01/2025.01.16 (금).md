# [⭕️ 1로 만들기 (https://www.acmicpc.net/problem/1463)]
#알고리즘 #DP #백준 

## 요약
- dp\[i]의 정의는 결괏값을 구하기 위한 중간 상태가 아니라 현재 i라는 상태에서 구할 수 있는 최적의 결괏값임 (완결된 상태)

## 1. 문제
- 입출력
	- 어떤 수 N이 주어졌을 때, 3으로 나누거나 2로 나누거나 1을 뺴는 세 가지 방법을 활용하여 1로 만드는 최소 연산 횟수 출력

## 2. 접근
- 접근 방식
	1. dp 배열을 N+1개 셀로 선언 후 N(최댓값)으로 초기화
	2. iterator i = N → 1 방향으로 순회
	3. dp\[i]의 값은 i에 3배, 2배, +1한 배열의 값 중 최솟값에 1을 더한 값으로 결정됨
	4. 마지막에 dp\[1]을 return
	
- 잘못된 부분
	- 풀이는 맞았지만, 다른 사람들의 풀이를 보며 접근 방식이 잘못되었다는걸 깨달음
	- 내 dp 배열에서 dp\[i]는 i에서 1로 가는 최소 연산 횟수가 아니라 i에서 N으로 가는 최소 연산 횟수였음 
	  (i의 배수를 비교하고, dp\[1]을 return함)

## 3. 핵심 포인트
- dp의 각 셀의 의미
	- 각 셀은 어떤 최종 목적지로 가기 위한 길목 위에 있는게 아니라 완결된 상태여야 함
	- 내 풀이: dp\[i]는 N에서 1로 가는 계산 과정 중 i를 만들기 위한 최소 연산 횟수
	  정석: dp\[i]의 정의는 숫자 i에서 1로 가는 최소 연산 횟수
	- 위와 같이 dp\[i]의 정의를 잘못 내리다 보니 잘못된 접근을 하게 됨


# [⭕️ 폰켓몬 (https://school.programmers.co.kr/learn/courses/30/lessons/1845)]
#알고리즘 #해싱 #프로그래머스 

## 요약
- `unordered_set`을 iterator를 사용하여 `vector`의 값으로 초기화할 수 있음

## 1. 문제
- 입출력
	- N개의 폰켓몬의 종류를 나타낸 배열이 주어졌을 때 
	  그중 N/2개를 선택 시 가져갈 수 있는 최대 폰켓몬의 가짓수 출력
- 조건
	- 폰켓몬의 종류는 중복일 수 있음

## 2. 접근 
- 접근 방식
	1. 폰켓몬의 종류 배열을  순회하며 `unordered_set`에 넣기
	2. `unordered_set`의 크기와 N/2 중 최솟값 return

## 3. 핵심 포인트
- 굳이 배열을 순회하지 않아도 아래 문법으로 `vector`를 `unordered_set`으로 만들 수 있음
```
unordered_set<int> s(nums.begin(), nums.end());
```
