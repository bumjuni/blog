# [❌ 구간 합 구하기 4](https://www.acmicpc.net/problem/11659)
#알고리즘 #백준 #누적합

> [!abstract] 요약
>  - 누적합: 배열을 순회하며 `시작 인덱스 ~ 현재 인덱스`까지의 원소의 합을 미리 계산하여 배열에 저장해 두는 것
>  - 초기 계산에는 $O(n)$, 배열 임의접근에는 $O(1)$ 소요

## 1. 문제
- 입출력
	- N개의 숫자 배열과 M개의 구간이 주어졌을 때 구간 합 출력
	
- 조건
	- N, M은 100,000 이하

## 2. 접근
- 접근 방식
	- N개의 배열을 M번 순회하며 각 배열의 구간 합 출력

- 막힌 지점
	- 최대 $100,000^2$번 배열을 순회하므로 시간초과
	- 누적합이 뭔지 몰랐음

## 3. 핵심 포인트
- 누적합
	- DP 처럼 `시작 인덱스 ~ 현재 인덱스`까지의 원소의 합을 배열에 저장
	- 매번 새로 계산하는 것이 아니라 이전 합에서 현재 인덱스의 값을 더해주면 됨
	- 계산에는 $O(n)$, 배열에 접근해 각 구간의 합을 구하는데는 $O(1)$
