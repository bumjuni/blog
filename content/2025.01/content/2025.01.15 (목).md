# [❌ 완주하지 못한 선수 (https://school.programmers.co.kr/learn/courses/30/lessons/42576)]
#알고리즘 #해싱 #프로그래머스

## 요약
- 각 값이 고유한 상태를 가지면 → key:value 해싱 알고리즘 
- 동일한 값이 있어 `map`이나 `set` 자료구조를 사용하지 못한다면 → `vector` + 정렬

## 1. 문제
- 입출력
	- 참가자 이름 명단 participant, 완주자 명단 completion이 주어졌을 때 완주하지 못한 한사람을 출력
- 조건
	- 동명이인이 있을 수 있음

## 2. 접근
- 접근 방식
	1. `unordered_map`에 먼저 participant를 모두 넣고, completion을 key로 하는 value를 true로 수정
	2. `unordered_map`을 순회하며 value가 false인 key를 색출

- 막힌 지점
	- `unordered_map`은 중복값을 허용하지 않음
	- 동명이인의 경우 다른 값으로 처리하지 못하여 동명이인 중 한 사람이 완주하지 못할 경우 해당 선수를 색출하지 못함
	- 다른 자료구조(`vector`)로 변경하자니 participant와 completion 배열을 $O(n^2)$으로 순회하는 방법밖에 없음

## 3. 핵심 포인트
- 정렬
	- participant와 completion이 거의 동일한 데이터임을 고려
	- 동일한 인덱스에서 서로 다른 값이 나오면 완주하지 못한 선수가 있음을 나타냄
	- completion 배열의 끝까지 같은 값으로 전개되면 participant의 마지막 선수가 완주하지 못한 것
	- $O(n)$으로 풀 수 있음
	- 이때 순회는 participant 배열보다 원소가 더 적은 completion 배열을 기준으로 해야 함

- bool이 아니라 숫자 status
	- `unordered_map`을 쓰고서도 문제를 풀 수 있음
	- key는 그대로 선수 이름, value에는 완주한 선수의 수
	- completion배열까지 봤을 때 value의 값이 0보다 큰 이름이 있다면 완주하지 못한 선수가 존재
