```
int solution(vector<int> priorities, int location) {    
    int target_process = priorities[location-1];
    int max_location = 0;
    int max_priority = 0;
    for (int i=0; i<priorities.size(); ++i) {
        if (max_priority < priorities[i]) { 
            max_priority = priorities[i];
            max_location = i;
        }
    }
    int cur = max_location;
    int answer = 0;
    while (true) {
        if (priorities[cur] >= target_process)   answer++;
        
        if (cur == location) break;
        cur = (cur + 1) % priorities.size();
    }
       
    return answer;
}
```

## Check
- 왜 오답인가?
	- 위의 코드는 타겟 프로세스의 인덱스(`location`)에 접근하면 종료
	- 따라서 `location` 이후에 더 높은 우선순위의 프로세스가 나오면 카운트하지 못함

- 왜 오답 풀이를 냈는가? 
	- 문제에 주어진 테스트 케이스만 고려함
