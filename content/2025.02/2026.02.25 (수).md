## 0. 문제
- 입출력
	- 기록 ID, 차 ID, 대여 시작일, 대여 종료일로 구성된 `CAR_RENTAL_COMPANY_RENTAL_HISTORY` 테이블이 주어졌을 때, 
	  차 ID(`CAR_ID`)와 '2022-10-16'에 대여 가능한 차량은 '대여 가능', 그렇지 않은 차량은 '대여중'으로 표시한 `AVAILABILITY`로 구성된 테이블을 반환

## 1. PLAN
1. `SELECT`에서 `IF` 사용
	- SQL문에서 기존 테이블에 없는 새로운 column을 만드는 것은 `SELECT`문에서만 가능
		⇒ `SELECT`문에서 `IF`로 `AVAILABILITY` column 생성
	- `IF`문에서 조건을 걸 때 테이블의 모든 행에 대해 수행하면 안됨 
		⇒ `GROUP BY`로 차량ID를 묶기
		⇒ 어떤 기준에 의해 그룹핑 되는지 알 수 없음. 오답

## 2. DO
```
SELECT C.CAR_ID, IF (START_DATE <= DATE '2022-10-16' AND END_DATE > DATE '2022-10-16', "대여 가능", "대여중") AS AVAILABILITY
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY AS C
GROUP BY C.CAR_ID
ORDER BY CAR_ID DESC
```

## 3. CHECK
- 문제점
	1. `IF`의 조건이 잘 적용되지 않고, 잘못된 행이 '대여중'으로 표시됨
