# [⭕️ 학점 계산](https://www.acmicpc.net/problem/2754)
#알고리즘 #백준 #문법 

> [!abstract] 요약
> - 출력값의 소수점을 고정하는 문법
>  `cout << fixed << setprecision(n) << <출력값>`

## 1. 문제
- 입출력
	- 고정된 알파벳 : 숫자 학점 값에 대해, 알파벳이 주어지면 대응되는 숫자 학점 출력

## 2. 접근
- `unordered_map`
	- 알파벳 학점을 `'A': 4.0, 'B': 3.0, 'C': 2.0`으로 매칭
	- 숫자 학점을 `'+': +0.3, '0': +0.0, '-': -0.3`으로 매칭
	- 주어진 알파벳 학점을 key로 하여 숫자 학점 계산 후 출력

- 막힌 지점
	- 소수점 출력: 변수를 `float`로 선언해도 `4.0`이 `4`로 출력됨

## 3. 핵심 포인트
- 출력값의 소수점을 고정하는 문법
	```
	cout << fixed << setprecision(1) << score;
	```
- `setprecision(int n)`의 n 만큼 소수점 자릿수가 출력됨
