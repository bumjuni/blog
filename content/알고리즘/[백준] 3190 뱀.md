
문제: https://www.acmicpc.net/problem/3190

## 문제점

1. 테스트케이스 실패1: 테스트케이스 2번과 3번이 같은 값이 나옴
2. 테스트케이스 실패2: 테스트케이스 2번에서 1초 작은 값이 나옴
3. 코드 구조: 플래그 변수를 사용하고, 뱀의 좌표를 저장한 `deque`를 계속 순회해야 함

## 해결
### 1. 2번과 3번 테스트 결과 같은 문제 해결
- 이동 후 비교하기

 **원인**
- 테스트케이스 2번 결과 == 3번 결과인 이유
	- 2번과 3번은 같은 경로로 움직이되, 길이가 다름
	- 2번: 길이 4, 벽에 부딪혀 종료
	- 3번: 길이5, 머리가 꼬리에 부딪혀 종료


- 이동 후 비교가 해법인 이유
	- 비교 후 이동하면 1초 이전 값의 머리를 가지고 비교하게 됨
	- 3번 테스트 케이스에서 꼬리에 도착하기 1초 전의 머리 위치를 가지고 비교함
		- n초: n-1초의 머리 위치로 잘못된 비교 & 이동(부딪히는 조건을 벗어남)
		- n+1초: n초의 머리 위치로 비교하더라도 더이상 부딪히는 조건이 아님

### 2. 결과값이 1초 작은 문제 해결
- 게임 시작 전 초기값을 1초가 아닌 0초로 설정

**원인**
- 결과값이 1초 작은 이유
	- 문제에서 주어지는 회전은 "게임 시작 n초 후"
	- 0초가 아닌 1초에서 시작하느라 게임 시작 n-1초 후에 회전함
	- 결과적으로 다른 경로로 이동하게 됨

- 테스트케이스 1번, 3번은 정답이 나오는 이유
	- 조건이 복잡하지 않고, 먹어야 할 사과는 다 먹었기 때문에 우연인 것으로 보임
	- 1초 더 가지고 시작했으나, 1초 덜 이동했기 때문에 정답이 나오게 됨

### 3. 코드 구조 문제 해결
- 이중배열로 보드 활용 + `deque`로 뱀의 위치 추적

- 왜 뱀의 정보를 보드와 덱 이중으로 저장할까?
	- 덱: 머리/꼬리의 위치를 변경하기 용이함
		- 덱에만 저장 시 머리의 위치와 몸의 위치가 같은지 덱 전체를 순회해야 함
	- 보드: 뱀의 머리와 몸이 부딪히는 경우를 판별하기 위함
		- 보드에만 저장 시 머리/꼬리 위치 수정이 어려움
